# ZipCare – Luggage & Bag Zipper Repair

A front-end website designed to provide information about zipper repair services for luggage, handbags, and leather bags.

## About the Project

ZipCare is a web development project focused on presenting zipper repair services through a simple, user-friendly website. It helps visitors explore repair services and understand the available options.

## Features

- Clean and user-friendly interface
- Service information and descriptions
- Responsive website layout
- Interactive elements using JavaScript
- Service-related images and visual content

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` – Website structure
- `style.css` – Styling and layout
- `script.js` – Interactive functionality

## Purpose

The purpose of this project is to apply front-end web development skills to create a practical service-based website.
